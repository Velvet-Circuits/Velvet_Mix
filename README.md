# Velvet Mix

Realtime broadcast mixer for Linux.

Download the latest `software-audio-mixer-<version>-linux-amd64.tar.gz` from the releases of this repository.

```bash
tar xzf software-audio-mixer-*-linux-amd64.tar.gz
cd software-audio-mixer-*-linux-amd64
./install.sh
```

Remove it with `./uninstall.sh` from the same archive. Sessions in `~/.config/software-audio-mixer` stay.

The console is at <http://127.0.0.1:8765/>. The application menu entry is Velvet Mix.

The first start opens audio for five days. Paste a license in Setup to keep audio open after that.
